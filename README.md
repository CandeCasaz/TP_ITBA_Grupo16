## Sitio web para la Mueblería #Hermanos Jota" cuenta con:
- Inicio: con un hero-banner, y productos destacados.
- Catálogo: donde se ven todos los muebles que ofrecen y un campo de búsqueda. Todos cuentan con "Ver más..." donde se puede observar más información de cada uno junto con un botón de "Añadir al Carrito". En el nav-bar existe un carrito simulado que cuenta las veces que se aprieta ese botón.
- Contacto: cuenta con un formulario donde se puede completar con el nombre, mail y mensaje, todo validado del lado del cliente con JavaScript.

## Tecnologías utilizadas:
- HTML.
- CSS.
- JAVASCRIPT.
